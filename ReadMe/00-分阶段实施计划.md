# ISPmanager 扩展优化 — 分阶段实施计划

依据 [05-ISP业务扩展与优化建议.md](./05-ISP业务扩展与优化建议.md)。**每完成一步会写入变更文档，并等待确认后再做下一步。**

## 原则

1. 先修现有逻辑（文档第 3 节），再开 P0 大功能（第 2 节）。
2. 每步可独立测试、可回滚。
3. 不一次做完整续费引擎 / 库存账本 / 流量出账（体量过大）。
