# ISPmanager 项目概览与功能模块

## 1. 项目定位

ISPmanager 是一套面向 **ISP / VPS / 边缘加速** 服务商的运营管理平台，覆盖：

- 后台运营：客户、合同、账单、产品、供应商、POP 资源、服务履约、监控运维、权限、通知与操作审计
- 客户门户（ISPweb）：自助注册、选购、下单支付、服务变更、VPS/边缘自助管理、咨询与在线客服

核心业务闭环：

```
产品目录 → 门户下单/支付 → 工单审批/自动开通 → 资源交付（VPS / Edge / IP / 带宽）
        → 服务实例生命周期 → 升降配变更与补差价 → 月度账单 / 渠道佣金 → 监控与运维
```

## 2. 仓库结构

```
ISPmanager/
├── backend/                 Django 6 + DRF + Channels（管理 API + 门户 API + WS）
│   ├── accounts/            用户档案、角色权限、API Token
│   ├── customer_manager/    客户、合同、账单、支付、渠道佣金
│   ├── resource_manager/    POP / 网络 / IP / VPS / 边缘加速 / 带宽
│   ├── service_manager/     工单、咨询、技术工单、实例、自助任务、变更、生命周期
│   ├── product_manager/     规格、模版、产品、升降配规则、发布
│   ├── supplier_manager/    上游供应商与资源同步
│   ├── operation_manager/   Zabbix 监控、流量 95、POP 品质、WebSSH
│   ├── system_manager/      系统参数、支付通道、IM 通知
│   ├── portal/              客户门户 API（公开 + 客户鉴权）
│   ├── log_manager/         全站统一审计日志（汇聚 + 写接口补记）
│   └── backend/             工程配置、JWT、OpenAPI、ASGI
├── frontend/                管理端 Vue 3 SPA（Element Plus）
├── deploy/                  Ubuntu 22.04 / 24.04 生产部署脚本
└── ReadMe/                  本技术文档
```

同级目录 **ISPweb** 为客户门户前端，调用 `/api/portal/` 与 `/api/auth/`。

## 3. 技术栈

### 3.1 后端

| 技术 | 版本/说明 | 用途 |
|------|-----------|------|
| Python | 3.12 | 运行时 |
| Django | 6.x | ORM、Admin、中间件 |
| Django REST Framework | — | REST API、过滤、分页、限流 |
| SimpleJWT | — | Access 2h / Refresh 7d，轮换 + 黑名单 |
| django-filter | — | 查询过滤 |
| drf-spectacular | — | OpenAPI 3 / Swagger / ReDoc |
| Django Channels + Daphne | — | WebSocket（VNC / WebSSH / POP SSH） |
| channels-redis | 可选 | 生产 Redis Channel Layer（多 gunicorn worker） |
| MySQL | 8 / utf8mb4 | 主库 |
| Gunicorn + Uvicorn worker | 生产 | ASGI HTTP + WS |
| 自定义 API Token | SHA-256 存储 | 系统集成 `Authorization: Token ispm_...` |

认证优先级：JWT Bearer → API Token。默认权限 `IsAuthenticated`，业务接口叠加模块权限（`HasPermission` / `IsAdminUser` / `IsCustomer`）。

### 3.2 管理端前端

| 技术 | 用途 |
|------|------|
| Vue 3 + Vite 7 | SPA |
| Vue Router 4 | 按权限码守卫路由 |
| Pinia | 登录态与权限缓存 |
| Element Plus | UI |
| Axios | `/api` 同源请求 |
| ECharts / vue-echarts | 监控与流量图 |
| noVNC | VPS 控制台 |
| xterm.js | WebSSH |

权限码与后端 `accounts.role_permissions` 对齐（模块 / 页面 / 查看·管理）。

### 3.3 客户门户（ISPweb）

Vue 3 SPA：官网选购、注册登录、控制台（服务 / 订单 / 账单 / 资源 / 咨询）、在线客服（QQ / 微信 / Telegram）。

### 3.4 部署与运行

- 开发：Django `runserver`（Daphne ASGI）+ Vite
- 生产：nginx 分域名托管两个 SPA，反代 `/api`、`/ws`、`/admin`、`/static`、`/media`
- 环境变量：`DJANGO_*`、`DB_*`、`PAYMENT_FRONTEND_URL`、POP 部署目录与上传上限
- CORS：未配置白名单时开发全放行；生产用 `DJANGO_CORS_ALLOWED_ORIGINS`

## 4. 功能模块与技术细节

### 4.1 账号与权限（accounts）

**功能**

- 系统账号 / 归属客户账号
- 7 个角色：超级管理员、管理员、客户管理员、运维人员、销售人员、**客户用户**、只读用户
- 权限目录可在线编辑；角色矩阵可配置原子权限（查看 / 管理）
- 用户级 API Token（前缀可见、哈希存储、过期、吊销）

**技术细节**

- `UserProfile` 一对一挂 `auth.User`
- 有效权限：`user_effective_permissions()`  
  - superuser → 全部启用权限码  
  - 客户账号 → 取其角色授权，再按 `customer./billing./service./resource.` 白名单裁剪  
  - 系统账号 → 角色授权；`is_staff` 额外并上账号管理权限
- 门户注册默认：`account_type=customer`、`role=customer`
- 客户账号仅允许绑定角色 `customer` / `readonly`，且必须绑定一个客户（一对一 `Customer.account`）

### 4.2 客户、合同、账务、渠道（customer_manager）

**功能**

- 客户档案（个人 / 企业）、信用额度、联系人、IM 账号
- 联系跟进记录、合同签署
- 月度账单、流量超额账单、账单明细（BillingItem）、在线支付与回跳 / Webhook
- 推广码绑定、渠道佣金、结算、不可变资金账本

**技术细节**

- 支付通道配置在 `system_manager.PaymentChannel`，凭据 Fernet 加密
- 门户与后台共用 `payment_service`：创建交易 → 网关下单 → webhook 入账 → 履约（开通 / 升配）
- 渠道账本 `ChannelFinanceLedger` 通过自定义 QuerySet 限制删除，保证审计不可篡改

### 4.3 资源管理（resource_manager）

**功能**

- 地理：大区 / 国家 / 城市
- 运营商、POP 节点（SSH、带宽、部署包、节点同步、PVE 创建虚机）
- 网卡、路由表、静态路由、策略路由
- IP 段 / IP 地址分配回收、隧道 IP 池
- VPS：规格、电源、克隆、VNC、同步、流量
- 边缘加速：GRE / VXLAN / WireGuard / Socks5 协议配置，下发节点
- 带宽分配与资源操作日志

**技术细节**

- POP 部署：上传安装包到 `POP_DEPLOY_UPLOAD_DIR`，SSH 推送到节点 `/tmp/pop_deploy`
- 节点同步：`push_to_node` / `sync_from_node` 分段下发（接口、路由、隧道、边缘等）
- VNC：签发 ticket，前端 noVNC 经 `ws/resource/vnc/{vps_id}/`
- 历史直连 VPS/Edge（无服务实例）仍出现在门户列表，但 `can_change_request=False`；批量回填用 `manage.py backfill_service_instances`

### 4.4 服务履约（service_manager）

**功能**

- 官网咨询 → 转服务工单 / 转技术工单（二者独立）
- 技术工单：技术故障 / 滥用 / 财务 / 接入，与开通工单分离，含 SLA 响应/解决时效
- 服务工单：新开 / 续期 / 升降配 / 终止；生命周期阶段推进
- 自动开通（VPS / 部分边缘协议）、人工交付清单与回传 API（Socks5 / 多实例 / 带宽 / 手动节点）
- 服务实例：激活 / 暂停 / 恢复 / 终止 / 转计费 / 分配 IP
- 门户自助：VPS 重装 / 快照任务骨架（镜像目录 + 进度，不调用节点）
- 变更：审批、执行、完成、回滚；门户升配补差价、降配下周期生效

**技术细节**

- 关键文件：`provisioning.py`、`manual_delivery.py`、`support_ticket.py`、`self_service.py`、`change_billing.py`、`change_executor.py`、`workflow.py`、`payment_fulfillment.py`
- 工单编号 `SO*`、技术工单 `ST*`、自助任务 `SS*`、快照 `SN*`、实例编号 `INS*`
- SLA 扫描：`manage.py process_support_sla`；自助任务：`manage.py process_selfservice_jobs --apply`
- 实例状态变更会同步绑定资源的客户与状态
- 门户变更 API：`change_quote` / `change_request`，不直接校验权限码，依赖 `IsCustomer` + 实例归属

### 4.5 产品目录（product_manager）

**功能**

- 规格维度（CPU / 内存 / 磁盘 / 带宽 / IP / 网卡）
- 产品模版 + 模版定价
- 上架产品、库存 / 容量、报价、发布日志
- 升降配规则（`ProductUpgradeRule`）

**技术细节**

- `product_manager.services` 统一计算资源月费、规格快照、报价
- 门户选购与后台报价共用同一套计价逻辑

### 4.6 供应商（supplier_manager）

**功能**

- 上游供应商档案、API 凭证、连通性测试
- POP 绑定、外部资源拉取与映射到本地 VPS/Edge
- 同步日志

用于「自有机房 + 转售上游」混合库存。

### 4.7 运维与监控（operation_manager）

**功能**

- 多 Zabbix 服务器接入、主机 / 监控项 / 图形同步
- 流量截取与 95 计费报告、计费规则模版
- POP 品质探测、节点遥测凭证、边缘接口质量采样与汇总
- WebSSH（POP / VPS / 监控主机 / 自定义）与命令模版

**技术细节**

- 门户监控限流 `portal_monitoring: 120/min`
- 节点质量上报 `edge_telemetry_ingest: 120/min`，按令牌隔离
- 流量查询支持自定义 `time_from` / `time_till`（门户最长 7 天）
- WebSocket：`/ws/operation/webssh/{target_type}/{target_id}/`

### 4.8 系统设置与通知（system_manager）

**功能**

- 系统参数（站点名、汇率、账期、客服 QQ/微信/TG、安全策略等）
- 公开参数接口供登录页 / 门户读取（`is_public=True`）
- 支付通道、IM 通道（Telegram / 企业微信应用 / 群机器人 / 客服 / 智能机器人 / 钉钉 / Webhook）
- 通知规则：按事件模板推送到指定通道。「资源异动」同时覆盖 VPS / 边缘加速 / POP / IP / 带宽
- 邮件：在「对内通知」填写客服邮箱、SMTP 主机/端口/账号后即可发送；`notify_email_enabled` 打开后随业务事件抄送

门户在线客服只读对外参数：`support_qq` / `support_wechat` / `support_wechat_qr` / `support_telegram` / `support_wecom_kf_url` / `support_email` / `support_phone`。IM 通道的 `default_target` 仅用于对内告警，不会回退到门户。

### 4.8.1 统一操作日志（log_manager）

**功能**

- 全站写操作留存：时间、人员、模块、对象、内容、详情、来源 IP
- 管理端「系统设置 → 操作日志」按功能模块筛选查看
- 汇聚已有分模块日志；未覆盖的写接口由中间件补记；登录 / 改密单独记账
- 权限码 `system.log.view`；客户门户账号不可访问

详见 [37-变更记录-统一操作日志.md](./37-变更记录-统一操作日志.md)。

### 4.9 客户门户 API（portal）

**公开**

- 注册、产品列表/详情/报价、可用地域、客服配置、官网咨询提交（5 次/小时）

**需客户 JWT 且绑定 Customer**

- 总览、资料、服务列表与变更、订单与直付、账单支付、VPS/Edge 自助操作（含重装/快照任务）、咨询列表、技术工单

门户权限类 `IsCustomer`：要求登录且 `User.customer` 存在，不走后台菜单权限树。

## 5. 跨模块关键流程

### 5.1 门户下单开通

1. 客户选产品 → `POST /api/portal/products/{id}/quote/`
2. 创建订单或 `direct-checkout` 生成账单 + 支付（含信誉值）
3. 支付成功 `payment_fulfillment` 推进工单 / 自动开通（`PopPoint.config_mode=auto`）
4. 生成 `ServiceInstance` 并绑定 VPS 或 Edge
5. **边缘加速 GRE/WG**：只预分配带宽、业务 IP、隧道地址段与 POP 管理 IP，资源保持「待配置」；客户在「我的服务 → 管理 → 协议配置」补全后「保存并下发」，节点生效后再激活实例，业务 IP 以 `/32` 主机路由下到隧道接口。Socks5 / 手动 POP 仍走人开交付。

### 5.2 服务变更

1. 门户 `change_quote` 计算原月费、新月费、剩余天数补差、升/降方向
2. 升配：预付账单 → 支付后执行变更
3. 降配：本月费用不变，预约下周期生效
4. 续期 / 终止：工单人工审批

### 5.3 权限生效

后台菜单与按钮：前端 `userHasPermission` + 后端 `HasPermission`。  
客户门户功能：账号类型 + 资源归属；角色授权主要用于后台预览与未来细粒度控制。

## 6. 非功能特性

| 项 | 实现 |
|----|------|
| 分页 | `StandardPagination`，默认 20 |
| 异常 | `custom_exception_handler` 统一 `code/message/detail` |
| 密码 | Django 校验器（长度 / 常见密码 / 纯数字等） |
| 文件 | POP 部署包最大默认 500MB |
| 时区 | `Asia/Shanghai`，`USE_TZ=True` |
| 审计 | 统一 `AuditLog` + 分模块日志汇聚；写接口中间件补记；登录 / 改密入账 |
