# ISPmanager 数据库表结构

> 由 Django ORM 元数据自动导出，覆盖业务应用全部 **88** 张实体表（不含 Django 内置 `auth_user` / `sessions` 等系统表）。

数据库引擎：**MySQL 8 / utf8mb4**，时区 `Asia/Shanghai`。

## 目录

- [用户账户管理（`accounts`）](#accounts) — 6 张表
- [客户管理（`customer_manager`）](#customer_manager) — 16 张表
- [资源管理（`resource_manager`）](#resource_manager) — 21 张表
- [服务管理（`service_manager`）](#service_manager) — 11 张表
- [产品管理（`product_manager`）](#product_manager) — 6 张表
- [供应商管理（`supplier_manager`）](#supplier_manager) — 5 张表
- [运维管理（`operation_manager`）](#operation_manager) — 16 张表
- [系统设置（`system_manager`）](#system_manager) — 6 张表
- [日志管理（`log_manager`）](#log_manager) — 1 张表

## 内置账号表（Django Auth）

| 表名 | 模型 | 说明 |
|---|---|---|
| `auth_user` | `django.contrib.auth.User` | 登录账号：用户名、密码哈希、邮箱、is_staff/is_superuser/is_active |
| `auth_group` / `auth_permission` | Django 权限 | 本项目业务权限以 `accounts_*` 角色授权表为准，不依赖 Django Group |
| `token_blacklist_*` | SimpleJWT | Refresh Token 轮换后的黑名单 |
