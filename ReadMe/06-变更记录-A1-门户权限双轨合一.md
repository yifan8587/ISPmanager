## 功能更新

1. 客户门户写操作与后台角色权限使用**同一套** `user_has_permission`。
2. 角色 **只读用户**（`readonly`）：可浏览服务/订单/账单/资源，**不能**提交变更、下单、支付、电源、VNC、改密、边缘下发。
3. 角色 **客户用户**（`customer`）：保持服务管理 / 变更 / VPS·Edge 操作；并补上 `billing.list.manage` 以便支付账单。
4. 「我的服务」列表的 `can_change_request` 会叠加变更权限；无权限时按钮禁用。
5. 总览接口增加 `capabilities`，前端可据此隐藏写操作。
