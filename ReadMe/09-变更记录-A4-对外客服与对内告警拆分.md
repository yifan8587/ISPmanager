# 变更记录 A4 — 对外客服与对内告警拆分

**阶段**：A（现有逻辑与安全）  
**步骤**：A4  
**日期**：2026-08-23  
**对应建议**：`05` 第 3.5 节；门户曾回退读取 Telegram IM `default_target`，与对内告警混淆

---

## 功能更新

1. **对外客服**单独成系统设置分类「对外客服」：QQ / 微信 / Telegram / 企微入口 / 邮箱 / 电话。
2. **对内告警**仍走「通知 / IM 对接」的通道 `default_target` 与通知规则。
3. `GET /api/portal/support-config/` **只读**公开 `support_*`，不再回退 IM 的 chat_id / 企微客服链接。
4. 新增 `support_wecom_kf_url`；迁移时若为空，会从已启用的企微客服通道拷贝一次入口链接。
5. 服务端缓存 `portal:public_support_config`（60 秒）；保存或删除 `support_*` 后立即失效。响应 `Cache-Control: no-store`。
6. 原先只有「基础设置」分类权限的角色，迁移时补上「对外客服」查看/修改权。
