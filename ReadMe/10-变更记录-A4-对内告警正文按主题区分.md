## 功能更新

1. 默认通知正文**不再**套同一套「触发前 / 本次变更 / 变更后」快照。
2. 每种事件只用自己的字段，例如：
   - 官网咨询：联系人、联系方式、需求
   - 客户收款：账单、金额、支付状态
   - POP 告警：对象、触发来源、说明
   - VPS / 工单 / 变更单：客户、编号、规格或变更类型
3. 每条通知固定包含：**主题 + 动作**、**操作人（或触发来源）**、**时间**。
4. 仅在确有字段差异（含 `→`）时附加「变更明细」，并继续脱敏。
5. 工单/变更/咨询/产品发布等上下文补上更准确的操作人与规格摘要。
