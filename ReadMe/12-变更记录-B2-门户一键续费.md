## 功能更新

1. 门户续费不再创建待审批的人工续期工单，改为：
   - 按当前实例月费 × 账期（月 / 季 / 半年 / 年）报价
   - 生成已审批的轻量 `RENEW` 工单 + 预付账单
   - 拉起现有支付渠道；支付成功后延长到期日
2. 到期计算：未过期从当前 `expire_time` 往后加；已过期或无到期日从现在起算。同时刷新 `suspend_at` / `recycle_at`，并同步 VPS / Edge 的 `expire_time`。
3. 已暂停 / 已过期实例付费成功后自动恢复运行。
4. 同一实例未支付的续费账单可复用，并允许改账期（支付中的账单不可改价）。
5. 汇率仍走现有支付换算；账单币种取实例有效币种（含 `CREDIT`）。本步不新增门户信誉额余额扣款。
