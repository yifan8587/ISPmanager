## 功能更新

1. 只对两类已入账业务失败自动退：
   - **新开开通失败**：`order_type=NEW`，账单 `PAID`，工单 `auto_provision_status=FAILED`，且**无实例**
   - **升配未执行**：`order_type=UPGRADE`，账单 `PAID`，工单 `FAILED`，关联变更单不是 `COMPLETED` 且 `executed_at` 为空
2. **不自动退**：开通成功、已有实例、`INSUFFICIENT` / `PAID_PENDING` / `NONE`、已履约续费 `RENEW`、月结账单、未付账单。
3. 管理员可对库存不足等人开场景 `force=True` 手动发起退款；支付成功后不会立刻退，避免和补库存重试打架。
4. Stripe / PayPal **原路退**；支付宝 / 微信 / 现金 / 转账 / 信用付等标 `pending_manual`，由管理员确认。
5. **不回滚** `paid_amount`（审计）；另记 `refunded_amount`。退款成功后尽量作废待结算佣金；已结算佣金只记日志，不回滚退款。
6. 门户第一期只展示退款态，不开放客户自助退。已履约续费不会自动退。

状态机：

```
succeeded → refunding → refunded          # Stripe / PayPal 成功
                 └──→ pending_manual     # 网关不支持 / 失败 / 无交易
账单：paid → refunding → refunded
```
