## 功能更新

1. 工单在报价锁定时拍摄当时的 `to_cny` 汇率表，写入 `fx_snapshot` / `fx_quote_currency` / `fx_locked_at`。
2. 锁定时机：门户下单、后台建单、咨询转工单、升配变更、一键续费；审批与出预付账单时若尚未锁定则补锁。
3. 预付账单走在线支付时，账单币种 → 渠道币种的换算**优先用工单快照**，不再跟支付当天的系统汇率。
4. 月结出账时，有快照的实例按工单锁定汇率折算；没有快照的历史工单、无工单的裸资源仍用实时汇率。
5. 已锁定工单默认不改快照；未支付续费改账期会按新报价刷新快照。本步不做实时牌价源、客户自选汇率或发票。
