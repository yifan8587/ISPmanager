## 功能更新

1. 产品新增 `billing_mode`：`flat`（包月，默认）/ `95th` / `avg` / `transfer_quota`。
2. 配套字段：`transfer_quota_gb`（流量包每月 GB）、`overage_unit_price`（流量包每 GB，或 95/平均每 Mbps）。
3. 写接口校验：流量包必须填额度；95 / 平均必须填承诺带宽（沿用现有 `bandwidth_mbps`）。
4. 报价、产品列表/详情、门户下单快照带上计费模式，供 C3 出超额明细使用。
5. **本步不出超额账单、不限速、不读流量报告。** 月结仍按 `monthly_price` 收基础月租，历史包月产品行为不变。
