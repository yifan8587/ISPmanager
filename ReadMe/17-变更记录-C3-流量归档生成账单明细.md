## 功能更新

1. 归档流量报告后，按产品计费模式计算超额并写入账单明细：
   - `95th`：`max(0, 95峰值Mbps − 承诺带宽) × 超额单价`
   - `avg`：`max(0, 平均Mbps − 承诺带宽) × 超额单价`
   - `transfer_quota`：`max(0, (入+出)GB − 流量包额度) × 每 GB 单价`（1 GB = 1024³ 字节）
2. **独立流量超额账单**（`billing_kind=traffic_overage`），不写进会被 `generate_bill()` 全量重建的月结单。同一客户、同一账期、同一币种的未付超额单可追加明细。
3. 幂等：`BillingItem.traffic_report` 一对一，同一报告不重复出账。
4. 默认安全：包月 / 超额为 0 / 单价为 0 / 无客户（如纯 POP 报告）/ 报告未算出数据 → 跳过。已付、退款中或支付中的超额单不再改金额，改为新开一张未付超额单。
5. 计费档优先用工单下单快照（C2），没有则回退当前产品。超额金额不参与推广优惠。
6. 归档接口失败不影响报告已归档；命令 `generate_traffic_billing_items` 可补扫。

本步不做超额告警、限速、信誉额预授权，也不做门户「本月已用 / 套餐额度 / 预测 95」完整产品。
