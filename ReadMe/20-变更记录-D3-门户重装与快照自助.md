## 功能更新

1. **镜像目录** `OsImage`：管理端维护，门户重装只列出已上架项。首次打开门户目录时写入预置 Debian 12 / Ubuntu 24.04 / CentOS Stream 9。`node_template_ref` 预留给后续 PVE 模板。
2. **重装任务**：门户 `POST /api/portal/vps/{id}/reinstall/` 选择镜像、可选新密码，生成 `SelfServiceJob`（`reinstall`）。同一 VPS 同时只能有一张待处理/进行中任务。
3. **快照档案** `InstanceSnapshot`：创建 / 列表 / 恢复 / 删除。达到 `vps_snapshot_retain_count`（默认 7）时过期最早的可用快照。
4. **任务处理**：默认停在 `pending`。管理端「自助任务」可完成/失败/取消；命令 `process_selfservice_jobs --apply` 按骨架完成（改 VPS `os_type`/`os_version`、可选写密码并擦除 payload、快照标为可用）。**不调用节点 / PVE**。
5. 通知事件 `service_selfservice`。列表接口不回传明文密码。

本步不做：防火墙 / 安全组、反向 DNS、企业子账号、真实 qm snapshot / 原地重装、cloud-init 推节点。

## 验证

```bash
cd ISPmanager/backend
python manage.py migrate
python manage.py sync_permissions
python manage.py test service_manager.tests_self_service --keepdb
# 5 项已通过：重装完成擦密码、门户互斥、快照创建/恢复、无实例 VPS、镜像 CRUD
```

门户对一台运行中 VPS 提交重装后应出现待处理任务，再次提交应 400。管理端点「完成」或：

```bash
python manage.py process_selfservice_jobs --dry-run
python manage.py process_selfservice_jobs --apply
```

`--apply` 后 VPS 系统档案应变为所选镜像；payload 中不再有密码。快照创建后未 apply 前不能恢复；apply 后可恢复。
