# 功能实现检查与完善清单

**日期**：2026-08-23  
**范围**：`ISPmanager` 后端 + 管理端前端、`ISPweb` 客户门户  
**对照**：`01` 模块说明、`05` 扩展建议、阶段 A1–D3 变更记录  
**方法**：通读模块与路由，交叉核对 API / 页面 / 权限 / 定时任务；高危项均回源码核实

本文区分三类问题，避免把「骨架设计边界」写成漏洞：

| 类型 | 含义 |
|------|------|
| **安全漏洞** | 鉴权、越权、密钥、财务可被绕过 |
| **业务未闭环** | 字段/API/页面已有，钱或机器对不上 |
| **体验与对齐** | 前后端漏页、按钮未按权限隐藏、缺二次确认 |

## 1. 结论

平台主链路可用：**产品上架 → 门户注册/下单/支付 → 工单开通 → VPS/边缘交付 → 实例变更与续费 → 账单与监控**。阶段 A–D 的骨架已落地并确认。

与专业 ISP 控制台相比，当前短板不再是「完全没做」，而是：

1. **高危隔离已按 S1 收口**；中危公开接口限流与门户审计见 S2（已确认）。客户 JWT 与后台 JWT 仍打同一 `/api`。
2. **A–D 多为记账骨架**：到期默认只催缴、重装/快照不调节点、国内通道退款转人工。降配预约已有执行器（S4），仍不调节点 resize。
3. **生产 cron（S4）**：deploy 已挂到期催缴、15 分钟维护、日终出账/SLA；自助重装命令仍不挂。
4. **门户只读按钮已按 S3 用 capabilities 隐藏**；注册仍无验证码。

| 统计 | 数量 |
|------|------|
| 安全：高 / 中 / 低 | 7 / 8 / 6 |
| 业务未闭环：P0 / P1 / P2 | 8 / 12 / 8 |
| 前后端对齐问题 | 11 |
| 命令已写、deploy 未挂 cron | 1（自助重装，刻意不挂） |

## 3. 安全漏洞

门户 JWT 与管理端 JWT 打同一 `/api`、`/ws`。客户角色默认带 `service.view` / `service.manage` / `resource.vps.manage`，因此「客户打管理端路由」是真实攻击面，不是理论假设。

### 3.1 高

| 编号 | 问题 | 证据 | 影响 |
|------|------|------|------|
| S-H1 | VNC WebSocket 只查是否登录，不查 VPS 归属、不查 `resource.vps.manage` | **已修（S1，已确认）** | 现按 REST 对齐：权限码 + 客户只能连自己的 VPS。 |
| S-H2 | POP WebSSH 任意已登录用户可连任意 POP | **已修（S1，已确认）** | 仅系统账号 + 资源/运维管理权限。 |
| S-H3 | 运维 WebSSH 同样无系统账号门槛；`custom` 可由客户端指定 host/凭据 | **已修（S1，已确认）** | 客户账号 4403；与 REST `WebSSHResolveView` 对齐。 |
| S-H4 | 服务统计 / 账单预览无租户隔离 | **已修（S1，已确认）** | `ServiceSystemPermissionMixin`，客户 403。 |
| S-H5 | 客户可配置全局开通 Hook → 服务端 SSRF | **已修（S1，已确认）** | 仅系统账号；保存/调用时拒绝内网与元数据 URL。 |
| S-H6 | 未设环境变量时默认不安全 | **已修（S1，已确认）** | `DEBUG=false` 或 `DJANGO_PRODUCTION=1` 时拒绝默认密钥 / `*` / CORS 全放行。 |

## 7. 建议完善顺序

不新开大模块的前提下，建议按「先堵住洞，再让已有骨架真跑起来」：

### 第一批（安全，可独立一步）

1. WebSocket：`IsSystemAccount` 或对象归属 + 权限码，与 REST 对齐；禁止客户打 POP/运维 SSH。
2. `ServiceStats` / `ServiceBilling` / `ServiceProvisionHook`：系统账号，或客户强制 scope；Hook URL 禁内网。
3. 门户线下入账改为仅后台财务确认；门户只保留在线 `init`。
4. 生产启动：无 `DJANGO_SECRET_KEY` / `DEBUG=true` / CORS 全放行则拒绝启动。
5. 注册、Webhook、交付 Callback、Token 校验加限流。

### 第二批（已有骨架闭环）

1. 降配到期执行器；升配执行后可选下发/工单。**S4 已确认**
2. 超卖标志在开通校验与预占共用一套规则。**S4 已确认**
3. deploy 补 cron：预占释放、退款补扫、流量出账、SLA、逾期账单。**S4 已确认**
4. 门户用 `capabilities` 隐藏只读按钮；管理端工单/实例/变更加 `canManage`。**S3 已确认**
5. 危险操作补确认（交付提交、自助完成、建快照、改密）。**S3 已确认**

### 第三批（独立立项，05 原清单）

节点真实重装/快照、国内通道原路退、发票、子账号、防火墙/PTR、维护窗禁售、状态页。邮件见 S5，余额见 S6，对账见 S7，流量归档见 S8。
