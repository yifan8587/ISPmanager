## 功能更新

1. **S-H1 VNC WebSocket**：连接前校验 `resource.vps.manage` / 控制台权限；客户账号只能连自己的 VPS。拒绝关闭码 `4403`。
2. **S-H2 POP WebSSH**：仅系统账号 + 资源/运维管理权限，客户 JWT 不能开节点 SSH。
3. **S-H3 运维 WebSSH**：与 REST `WebSSHResolveView` 对齐（系统账号 + 运维管理），含 `custom` 目标。
4. **S-H4 统计 / 账单预览**：`ServiceStatsViewSet`、`ServiceBillingViewSet` 改为 `ServiceSystemPermissionMixin`，客户 403。
5. **S-H5 开通 Hook**：同样仅系统账号；保存与调用时拒绝内网 / 环回 / 链路本地 / 元数据 URL。运维内网回调可设 `DJANGO_WEBHOOK_ALLOW_PRIVATE_URLS=1`。
6. **S-H6 生产启动校验**：`DEBUG=false` 或 `DJANGO_PRODUCTION=1` 时，拒绝默认 `SECRET_KEY`、`ALLOWED_HOSTS=*`、CORS 全放行；生产还拒绝默认库密码。开发 `DEBUG=true` 且未开生产开关时不拦截。
7. **S-H7 门户线下入账**：门户不再列出或接受现金 / 银行转账；线下入账只走后台财务。

## 生产部署注意

上线前必须设置：

```bash
DJANGO_PRODUCTION=1
DJANGO_DEBUG=false
DJANGO_SECRET_KEY=<随机长密钥>
DJANGO_ALLOWED_HOSTS=admin.example.com,portal.example.com
DJANGO_CORS_ALLOWED_ORIGINS=https://admin.example.com,https://portal.example.com
DB_PASSWORD=<非默认密码>
```

缺省启动会抛 `ImproperlyConfigured`。
