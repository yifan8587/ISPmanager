# 变更记录 S2 — 中危限流、审计与 Token 收口（S-M1～M8）

**步骤**：S2  
**日期**：2026-08-23  
**对应**：`21` 第 3.2 节中危项  
**前置**：S1 已确认

---

## 功能更新

1. **S-M1 注册限流**：`RegisterView` 按 IP `8/hour`。完整邮箱验证仍属 P1，本步不做。
2. **S-M2 人开回传限流**：公开 `ManualDeliveryCallbackView` 按 IP `60/min`。
3. **S-M3 支付 Webhook 限流**：`PaymentWebhookView` 按 IP `120/min`（验签逻辑未改）。
4. **S-M4 Token 预检限流**：`APITokenVerifyView` 按 IP `20/min`。
5. **S-M5 门户审计**：电源 / 改密 / VNC 票据 / 协议配置 / 下发写入 `ResourceOperationLog`（有实例则同时写服务日志）。重装 / 快照 / 恢复 / 删除在自助引擎记账。**不记录明文密码**。
6. **S-M6 VNC 票据**：REST 增加 `Cache-Control: no-store`。noVNC 子协议固定 `binary`，JWT 仍走 query。WebSSH 改为 `Sec-WebSocket-Protocol: access_token, <JWT>`，query `token=` 仍兼容。
7. **S-M7 节点 TLS**：`PemanagerClient` 默认跟随 `PEMANAGER_SSL_VERIFY`（`DEBUG=true` 默认关，生产默认开；`DJANGO_PEMANAGER_SSL_VERIFY` 可覆盖）。VNC 节点 `wss` 同样遵守。
8. **S-M8 API Token**：仅系统账号可签发；客户仍可列出 / 撤销自己的令牌。管理端代客户签发仍允许。

## 变更文件

| 文件 | 变更 |
|------|------|
| `backend/backend/throttles.py` / `settings.py` | 公开 IP 限流类与默认速率 |
| `backend/portal/views.py` / `audit.py` | 注册限流、写操作审计、VNC no-store |
| `backend/service_manager/views.py` / `self_service.py` | 回传限流、自助任务审计 |
| `backend/customer_manager/views.py` | Webhook 限流 |
| `backend/accounts/views.py` | Token 预检限流；签发仅系统账号 |
| `backend/resource_manager/pemanager_client.py` / `ws_auth.py` / `vnc_consumer.py` | TLS 默认、WS 子协议取令牌 |
| `frontend/src/api/wsAuth.js` 及 WebSSH 调用点 | JWT 不再放入 WebSSH URL |
| `backend/*/tests_s2*.py` 等 | 覆盖限流、审计、签发、TLS |
