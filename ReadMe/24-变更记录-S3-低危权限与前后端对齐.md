## 功能更新

1. **S-L1**：门户资料 PATCH 需要 `customer.detail.manage`。只读角色 403；默认客户角色已授权。
2. **S-L5**：空应用 `log_manager` 移出 `INSTALLED_APPS`（无模型、无统一审计查询）。
3. **管理端按钮**：工单 / 实例 / 变更写操作按页面 `canManage` 隐藏。
4. **菜单与权限码**：服务全景改用 `service.overview`；通知页改用 `system.notify.manage`；咨询页认 `service.inquiry.manage`。
5. **路由预览对齐**：用户 / 角色 / WebSSH / Zabbix / 模版 / 计费规则的 `ROUTE_PAGE_PERMISSIONS` 与路由守卫同为 manage。
6. **二次确认**：人开提交交付；自助完成 / 失败 / 取消；门户建快照、改 Root 密码。
7. **门户 capabilities**：选购、支付、工单、电源 / 重装 / 下发按能力隐藏；资源列表可打开管理抽屉。

未做（非本步代码缺口）：S-L2 真改 VM 密码、S-L3 Admin 2FA、S-L4 改 JWT 存储、S-L6 直付审批策略、邮箱验证、新管理页、降配执行器 / cron。
