## 功能更新

1. **SMTP**：`EMAIL_*` 从环境变量读取。开发默认 console；生产默认 SMTP。deploy `.env` / 运行时环境已预留。
2. **总开关生效**：`notify_email_enabled` 打开后，`im_services.notify()` 在 IM 之外补发邮件。失败不阻断主流程。
3. **客户邮件**：催缴（`service_expiry`）、逾期（`billing_overdue`）、开通成功、工单提交/回复/解决/关闭。指派等内部动作不发给客户。
4. **运维抄送**：`notify_email_recipients`，留空则用 `support_email`。发件人可用 `notify_email_from`。
5. **管理端**：通知页增加「邮件」页签，可发测试邮件（不要求先打开总开关）。

未做：注册邮箱验证、站内信、HTML 模板、邮箱验证码。
