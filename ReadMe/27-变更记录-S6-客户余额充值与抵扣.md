## 功能更新

1. **流水**：新增 `CustomerBalanceLedger`。余额只通过充值入账、账单抵扣、人工调账、充值退回变更；后台 PATCH / Django Admin 不能直接改 `balance`。
2. **充值**：门户创建 `billing_kind=wallet_recharge` 未付账单，走现有在线支付。入账幂等；充值单不记渠道佣金、不开通业务。
3. **抵扣**：门户可用余额付普通账单（月结 / 超额等）。禁止用余额付充值单；账单币种须与钱包币种（`default_currency`，默认 CNY）一致。余额不足时可部分抵扣。
4. **退款**：充值单退款完成后按原入账金额扣回，幂等。已花掉的余额可能把账户打成负数。
5. **管理端**：客户详情可调账并看流水。`POST /api/customer/customers/{id}/adjust-balance/`，`GET …/wallet-ledger/`。
6. **门户**：账单中心显示余额、充值弹窗、「余额支付」；仪表盘 / 资料页可跳转充值。权限沿用 `billing.list.manage`。

未做：多币种钱包、信誉额自动授信、发票、支付宝/微信原路退完整对接。
