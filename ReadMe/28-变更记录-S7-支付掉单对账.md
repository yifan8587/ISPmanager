## 功能更新

1. **查单**：`query_payment()` 覆盖 Stripe / PayPal / 支付宝 / 微信 / Airwallex / 银联。PayPal `APPROVED` 会先 capture。银联需要下单时的 `txnTime`（已写入 `checkout_payload`）。
2. **对账**：未终态交易先向服务商查单。成功则走现有入账；失败/关闭则标失败。仍未付且本地已过期才标 `expired`。**查单失败不改成过期**，避免 webhook 丢失时把已付款交易丢掉。
3. **节流**：未过期交易 45 秒内不重复查单。过期交易每次扫描必查。
4. **定时**：`expire_payment_transactions`（已挂 15 分钟维护）改为对账后过期。另提供 `reconcile_payment_transactions`（`--dry-run` / `--transaction-no` / `--force`）。
5. **轮询**：`GET /api/customer/payment-transactions/{transaction_no}/` 对未终态交易自动对账。门户与管理端现有轮询无需改路径。
6. **后台**：`POST …/reconcile/` 强制对账，仅系统账号。管理端扫码弹窗「刷新状态」走该接口。

未做：支付宝/微信原路退完整对接、发票、通道手续费账本。
