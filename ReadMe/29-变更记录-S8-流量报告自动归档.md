## 功能更新

1. **日终归档**：`generate_traffic_billing_items`（已挂 01:15）先把「已完成且窗口已关闭」的报告标成已归档，再按原逻辑出超额账单。
2. **关账口径**：默认只归档 **上一自然月及更早**（`time_till` 早于本月月初）。本月截取仍留给人工归档，避免 95 月中出账。
3. **命令**：`--no-archive` 只补扫；`--archive-only` 只归档；`--include-open-month` 连本月已结束窗口一并归档。`--dry-run` 不写库。
4. **管理端**：流量报告页说明日终会自动归档；上一自然月的「已完成」报告显示「待日终归档」。

未做：不从 Zabbix 自动生成月报；月结单仍只含包月租金；不限速、不告警。
