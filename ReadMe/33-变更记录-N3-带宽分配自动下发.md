## 功能更新

1. **带宽分配 CRUD 默认下发**：创建 / 更新 / 删除时 query 或 body 的 `push_to_node` 缺省为 `true`。
2. **VPS**：已同步且有 `source_ref` 时走 `allocate_vm_bandwidth`；未同步只保存本地。
3. **边缘**：有 `node_ifname` 时 upsert 带宽并 `apply_qos`；尚未下发隧道则跳过。
4. **无节点 API**：跳过下发，本地建档成功。
5. **节点失败**：同一事务回滚，本地不留脏行；删除失败则本地记录保留。
6. **管理端**：带宽管理表单增加「同步到节点」开关（默认开）。VPS 详情「仅保存 / 保存并下发」默认不变。

未做：防火墙中心化、真 PVE 重装/快照、门户电源改 dry_run、JWT refresh。
