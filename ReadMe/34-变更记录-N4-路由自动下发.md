## 功能更新

1. **静态路由 CRUD 默认下发**：创建 / 更新 / 删除时 `push_to_node` 缺省为 `true`。有出接口则写 desired-route 并 `apply-system`；删除先删节点记录再全量 apply。
2. **策略路由 CRUD 默认下发**：同样缺省 push；有 from/to/fwmark（lookup 还需查找表）则 upsert policy-rule 并 apply。
3. **跳过不挡建档**：无节点 API、未选出接口、无匹配条件、未关联 POP → 只保存本地。
4. **节点失败**：同一事务回滚；删除失败则本地记录保留。
5. **管理端**：POP 详情路由/策略弹窗增加「同步到节点」（默认开）；静态路由可选出接口（节点下发需要）。

未做：防火墙中心化、真 PVE 重装/快照、门户电源改 dry_run、JWT refresh。
