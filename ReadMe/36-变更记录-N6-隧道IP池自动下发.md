## 功能更新

1. **隧道地址段 CRUD 默认下发**：创建 / 更新 / 删除时 `push_to_node` 缺省为 `true`。
2. **创建/更新**：按名称幂等 upsert 节点 `TunnelIPPool`，成功回写 `source_ref` / `is_synced`。
3. **删除**：按 `source_ref` 或同名匹配删除节点池。
4. **无节点 API**：跳过下发，本地建档成功。
5. **节点失败**：同一事务回滚；删除失败则本地记录保留。
6. **专用下发按钮不变**：`push_to_node` action 仍默认 `dry_run=true`，确认后再真下发。
7. **管理端**：新建/编辑表单增加「同步到节点」（默认开）。

未做：防火墙中心化、真 PVE 重装/快照、门户电源改 dry_run。
