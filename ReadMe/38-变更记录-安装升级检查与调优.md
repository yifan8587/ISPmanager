# 变更记录 — 安装前检查与平滑升级

**日期**：2026-08-25  
**范围**：`ISPmanager/deploy` 安装与运维脚本

---

## 功能更新

1. **安装前检查** `preflight.sh`：操作系统、内存、磁盘、systemd、已有服务 / `.env` / 数据库 / 证书。
2. **自动判定全新或升级**：命中已有部署则走升级，不重置 `DJANGO_SECRET_KEY`、数据库密码、超级管理员密码。
3. **升级备份**：`/var/backups/ispmanager/<时间戳>/` 保存 `.env`、运行时环境、nginx、可选 `mysqldump`。
4. **系统调优** `tune-system.sh`：按内存设置 gunicorn workers、InnoDB buffer、低配补 swap、文件句柄、nginx keepalive。
5. **证书**：升级时已有证书则只重渲染 nginx，不重新签发。
6. **后置同步**：`sync_permissions`、`sync_audit_logs`。
7. **数据库**：应用账号已能连接时跳过 `ALTER USER`，避免升级改密。

```bash
sudo bash install.sh --check
sudo bash install.sh                 # 已有环境自动升级
sudo bash manage-service.sh update   # 同样先检查再调优
```

`FORCE_FRESH=1` 需同时 `CONFIRM_FRESH=1` 才允许在已有环境上按全新流程跑。
