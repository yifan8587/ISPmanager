# 变更记录 — IP 录入网关 / 掩码与 NAT 交付

**日期**：2026-08-31  
**范围**：资源管理 IP 地址块/地址列表、POP、产品、门户选购与服务 IP  
**对应**：单个 / 不连续 / CIDR 录入，本段掩码与网关供 VPS 配网；POP 仅能 NAT 交付时前端提示

---

## 问题

IP 列表原先只能按单条、起止、空白分隔列表补录，没有按 CIDR 带子网掩码、网关落库的方式，VPS 开通时拿不到本段网关。  
部分 POP 只能 NAT 交付，产品新建和门户选购时没有字段与提示，容易按公网直连理解。

---

## 行为

1. **IP 录入**  
   地址列表支持：单个 IP、多个不连续地址、起始-结束、CIDR 网段。  
   CIDR 必须属于所选地址块（可等于整块或为其子网）。单次最多 1024 条；更大段仍走地址块「解析 IP」。  
   可同时填写前缀长度（掩码）与本段网关；网关须落在所填 CIDR / 地址块内。未填网关时，单条 IP 继承所属地址块网关。
2. **地址块**  
   新增「本段网关」。解析 IP 时把块网关写入新地址。掩码由 CIDR 前缀推导。
3. **POP**  
   新增「IP 交付方式」：`public`（公网直连，默认）/ `nat`（NAT 交付）。  
   产品列表/新建、模版定价、门户卡片与详情、服务 IP 表在 NAT 时提示。
4. **门户已分配 IP**  
   列表带出网关、掩码（及边缘 `/32` 路由状态），NAT 节点另行提示。

---

## 部署

执行迁移 `resource_manager.0030_ip_gateway_and_nat_delivery`。

已有 POP 默认为公网直连；仅 NAT 节点需在 POP 编辑中改为「NAT 交付」。已有地址块可补填网关后，未单独覆盖网关的 IP 会自动继承。
